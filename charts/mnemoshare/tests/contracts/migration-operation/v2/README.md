# Migration operation contract v2

This immutable bundle is generated from the compiled process composition and generated persisted-format closure. It describes the `mnemoshare-migrate` executable, its fixed plan/apply/verify command grammar, governed process/profile IDs, primary and external persistence universes, digest transport, and the required down -> apply-exclusive -> verify -> up lifecycle.

The migration operation owns application-level format evolution. Deployment adapters own the explicit process down/up orchestration and must leave the application down after a committed migration failure; automatic rollback to the old writer is not permitted. `--expect-contract-fingerprint` is required on every command and makes the target binary attest its embedded operation grammar before persistence is opened. `--universe` selects one generated external persistence universe; it is never an ambient registry lookup. `--plan` selects the immutable plan artifact. `--expect-plan-digest` is an independent assertion over that artifact and is emitted alongside `--plan` by the deployment command grammar; the digest-only form remains available when a fresh plan lookup is explicitly desired.

`contract.json` is the generated canonical artifact. `README.md`, `schema.json`, and `conformance.json` are immutable v2 evidence. Re-run `go run -tags migrations ./tools/migrationoperationcontract -root . -check` to verify generated state. Any grammar change requires a new contract version.
